# RandDFit

## Run the app (Xcode)

1. Open `RandDFit.xcodeproj` in Xcode.
2. Select the **RandDFit** scheme and an iPhone simulator/device (iOS 16+).
3. In the **RandDFit** target, go to **Signing & Capabilities** and select your Team (if Xcode asks).
4. Press **Run** (⌘R).

## What you should see

- First launch shows **Get started** (difficulty + optional notification scheduling).
- Tap **Continue** to enter the main screen.
- Tap **Next workout** to generate another 1‑minute workout prompt.

## Notifications note

Scheduling notifications requires granting permission when prompted. If you deny permission, you can re-enable it in iOS Settings for the app (or reset simulator privacy settings).
